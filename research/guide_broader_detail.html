The report's original example: how to check an irrational slow mode

The long report's primary example and the focused paper's example use the same bath weights, but different rates 23 and 34. The primary example uses a₂₃ = 1799/8 and a₃₄ = 251/25. Its slow eigenvalue is a root of a cubic rather than a rational number. Do not mix the two examples' eigenvectors or overlap decimals.

1. Locate a root without trusting a decimal approximation

The exact characteristic polynomial factors into x times a cubic. Substitute the rational endpoints of (−337,−336), (−60,−59), and (−20,−19). The cubic has opposite signs at the ends of each interval. Continuity puts a root in each. A cubic has only three roots counting multiplicity, so these three distinct roots exhaust it and each is simple. The root closest to zero is the slow eigenvalue, and it is more than 39 units above either faster eigenvalue.

2. Obtain its vector from determinants

For a square matrix C, its adjugate is the transpose of the array of signed minors. The identity C adj(C) = det(C)I follows by expanding determinants along a row. Apply this to C = Mᵀ−xI. At an eigenvalue r, det(C) = 0, so any nonzero adjugate column is an eigenvector. The report prints four polynomial entries of such a column. Rational interval evaluation proves that its first entry is nonzero, allowing division to set w₁ = 1.

A polynomial can be evaluated using repeated multiplication and addition, for example 2x²+3x+4 = (2x+3)x+4. Replace x by an interval containing r and carry lower and upper bounds through those operations. This encloses each vector entry. It is not necessary to know r exactly as a decimal.

3. Enclose thermal weights using integer powers

To prove L ≤ q1/n ≤ U for positive numbers, it is enough to verify Lⁿ ≤ q ≤ Uⁿ. The certificate proposes nearby rational L and U, then accepts them only after exact power comparisons. Combining those intervals with the vector intervals encloses both overlaps.

−0.0937454280 < bh < −0.0937454279,
−0.0938488357 < bc < −0.0938488356.

Both intervals are negative and separated. Thus the colder preparation has strictly larger slow-mode magnitude. A separate checker reaches the same conclusion using matrix elimination and a bound on how far an approximate eigenvector can be from the true slow direction. The two methods provide different routes to the same claim.

The 11 manuscript comparisons check the matrix, cubic, cofactors, triplet table, root interval and printed overlap bounds. The standalone checker uses only Python's standard library.

When ordinary ordering is preserved at every time

1. Follow adjacent differences

For values f₁,…,fₙ on energy-ordered states, define yᵢ = fᵢ₊₁−fᵢ. The function is increasing exactly when every yᵢ ≥ 0. The generator L = Mᵀ acts on functions. Because L sends constant functions to zero, its action on differences is described by an (n−1)-by-(n−1) matrix K.

If every off-diagonal entry of K is nonnegative, the exponential-series argument from the contrast lesson gives etK ≥ 0. Therefore an initially increasing function stays increasing after evolution. This property is called stochastic monotonicity. It is stronger than merely having the contrast matrix from Step 14 nonnegative off the diagonal: the two matrices use different coordinates.

For example, one required four-state entry is K₂₁ = a₁₂−a₁₃. It equals −27 in both counterexamples here, so they do not have this ordering property. There is no conflict between them and a theorem that assumes it.

2. Translate function order into probability order

A probability distribution p is stochastically above q if the average of every increasing function is at least as large under p. For ordered discrete states, this says p has at least as much probability above every cutoff. Hotter Gibbs preparations have this order because increasing temperature shifts weight toward higher energies. A semigroup preserving increasing functions also preserves this order between distributions.

For a reversible process, the density ratio pᵢ/qᵢ evolves by the same function semigroup. On cooling, a Gibbs preparation divided by the bath distribution is increasing with energy, and it stays increasing. This is the extra fact needed to compare distances.

3. Use the supporting-line inequality for a convex function

A convex curve lies above each of its supporting lines. If g(y) is the slope of a supporting line at y, then Φ(x)−Φ(y) ≥ g(y)(x−y), and slopes can be chosen nondecreasing. Apply this to the density ratios of farther and nearer preparations and multiply by the bath probabilities:

DΦ(pfar‖q)−DΦ(pnear‖q)
≥ Σᵢ(pfar,i−pnear,i) g(pnear,i/qᵢ) ≥ 0.

On cooling, the last slope vector is increasing, so stochastic order gives the last inequality. On heating, both relevant orders reverse, leaving the same conclusion. With Φ(x) = x ln x this is KL divergence; with Φ(x) = |x−1|/2 it is total variation. KL is strictly convex, and finite-time matrix evolution is invertible, so distinct preparations have strict KL ordering at every finite time.

This argument does not need a simple slow mode. The separate asymptotic proof does: a nonnegative eigenvector for K lifts to a monotone slow function, whose Gibbs covariance derivative has a strict sign.

The ordering principle has established precedents: Baake and Sumner, Proposition 3.11, and Ohga, Hayakawa and Ito, Result 2 and SI D2. The latter's stated no-Mpemba result concerns energy; the supporting-line derivation above supplies the convex-divergence conclusion under the assumptions stated here.

How the energies alone can rule out cooling in the larger contrast family

1. A decreasing logarithmic slope cannot turn upward

Return to the contrast coordinates gₖ from Step 14. On cooling Rₖ = −gₖ is positive. Apart from a fixed positive factor, it is a decaying exponential times

[αₖ−Σᵢ≤ₖ eβ(Eₖ₊₁−Eᵢ)]/Z(β),
αₖ = Σᵢ≤ₖ eβb(Eₖ₊₁−Eᵢ).

The bracket is positive before the bath, with negative first and second derivatives. Its logarithm has negative second derivative. Also (ln Z)″ is the positive energy variance. Thus (ln Rₖ)″ < 0. If Rₖ starts with a nonpositive derivative at β = 0, its logarithmic slope becomes strictly negative for every later cooling β. This includes an initially zero derivative.

2. Reduce all starting slopes to one energy test

Shift E₁ to zero, put a = E₂, and let μ = (E₁+⋯+Eₙ)/n be the ordinary arithmetic mean energy. For the first contrast, g₁′(0) has the sign of μ−eβba(μ−a). If μ ≤ a, this is positive. Otherwise it is nonnegative exactly when

βb ≤ β* = ln[μ/(μ−a)]/a.

This one condition controls every later contrast too. For y = Eₖ₊₁ ≥ μ, the required starting slope is positive because a proper initial segment of the energy list has mean below μ. For y < μ, compare averages of the increasing function 1/(μ−t). Its average over [Eᵢ,y] is at least its average over [0,a]. Integrating gives

ln[(μ−Eᵢ)/(μ−y)]/(y−Eᵢ) ≥ ln[μ/(μ−a)]/a.

Exponentiation now bounds each term in the starting slope in the required direction. All cooling contrast magnitudes therefore decrease toward the bath. The nonnegative contrast evolution preserves their componentwise order, excluding finite-time weighted squared-distance reversal. The slow-projection argument also excludes asymptotic KL reversal.

3. Why this threshold is exact for the stated family

If βb > β*, the first contrast initially increases in magnitude. It can be made the simple slow mode by adding a small rank-one term to a reset generator. All G constraints then hold at equality, and finite positive preparations sufficiently near β = 0 witness cooling. This establishes sharpness for the G-only family. It does not assert that those rates satisfy the extra F constraints.

For four equally spaced energies, μ = 3a/2, so the threshold is βba ≤ ln 3. A spacing-independent consequence for n ≥ 3 is βb(Eₙ−E₁) ≤ n/(n−2). In four states the latter cutoff is 2. The proof bounds μ by placing every energy above E₂ at the highest energy and expands the resulting logarithms; every correction beyond n/(n−2) is positive. Distinct energies approaching that limiting arrangement show the constant cannot be improved for the G-only family.

4. The G-only amplitude limit is larger

Each contrast magnitude has a decreasing positive numerator. Its cold-to-hot ratio is therefore strictly less than the hot-to-cold denominator ratio. If the contrast compares the first m−1 states with state m, the first m terms of the cold denominator contribute at least m, and the other n−m hot terms contribute at most one each. The ratio is below n/m ≤ n/2. The slow-mode ratio is a nonnegative weighted average of these contrast ratios, so it too is below n/2.

This bound can be approached. Use energies 0, 1/L, L, 2L,… and the first contrast as the slow mode. With βh = L−2 and βc = L−1/2, the hot partition function tends to n and the cold one tends to 2; the two overlap numerators are both asymptotic to −1/L. The ratio tends to n/2. Thus the G-only amplitude supremum is 1−2/n, or 50% for four states. The full F-and-G premise gives the stronger 25% result proved earlier.

Why the general four-state test needs only endpoints and one possible extra point

1. Turn four derivatives into a curve in a plane

Use energies (0,a,b,c), with 0 < a < b < c. The ground-state probability increases with β, so g = π₁′ > 0. Define u = π₂′/g and v = π₃′/g. Since the four probability derivatives sum to zero, any fixed mode w has

b′(β) = g(β)Φ(β),
Φ = A+Bu+Cv,
A = w₁−w₄,   B = w₂−w₄,   C = w₃−w₄.

Only the sign of Φ matters. As β varies, (u,v) traces a curve. Exact differentiation shows u decreases strictly and v, considered as a function of u, has strictly positive curvature. Therefore a line A+Bu+Cv = 0 intersects it at most twice, counting a tangency twice.

2. Check the determinant signs behind that claim

A Wronskian is a determinant whose rows contain functions and their successive derivatives. It measures whether those functions can locally mimic one another. For g, gu and gv, elementary determinant operations give

W(g,gu) = g²u′,
W(g,gu,gv) = g³(u′)³ d²v/du².

Both determinants are negative for four ordered energies. To see the signs without trusting a graph, first add the constant function to replace derivatives of probabilities by probabilities. Multiply each column function by the positive partition function Z; the product rule changes the determinant by the positive factor Z to the number of columns. The columns now contain simple exponentials. Their derivatives multiply them by powers of −Eᵢ, producing a Vandermonde determinant: a product of energy differences. Expanding the Z column leaves only positive exponential weights times those signed products. The two required products have negative signs. Hence u′ < 0 and d²v/du² > 0.

3. Find the only possible interior extremum of Φ

Put c₀ = ab(b−a), c₁ = ac(c−a), c₂ = bc(c−b), γ = (c−a)/(c−b) > 1, and x = e−(c−b)β. The slope of the curve is

s(x) = dv/du = (c₂xγ−c₀)/(c₀+c₁x).

Its derivative has positive numerator c₀c₂γxγ−1+c₁c₂(γ−1)xγ+c₀c₁. Thus s increases strictly with x, from s(0) = −1 to s(1). If C ≠ 0, an interior extremum of Φ must solve s(x*) = −B/C. There is exactly one such solution when −1 < −B/C < s(1), and none otherwise. Equality at either endpoint is excluded. When C = 0, Φ is already monotone or constant.

For example, energies (0,1,2,3) give s(x) = (6x²−2)/(2+6x). If −B/C = −1/3, the unique solution is x* = 1/3 and β* = ln 3. One scalar equation replaces an unlimited temperature scan.

4. Test signs, not just zeros

On cooling, evaluate Φ at β = 0, at the bath, and at β* if it lies strictly between them. On heating, evaluate it at the bath, at infinity using Φ(∞) = w₁−w₂, and at β* if it lies on that side. A side has an ordinary asymptotic reversal exactly when its list contains both a strictly positive and a strictly negative value.

Why both signs? If b′ keeps one sign, b is monotone and its zero at the bath forces normal magnitude order. If b′ takes both signs on cooling, consider its last sign-changing zero before the bath. Just after that zero, b must head toward its bath value zero; just before it, b has the same nonzero sign but its derivative has the opposite sign. Its magnitude is therefore increasing there. The heating proof uses the first sign-changing zero after the bath. This produces a finite interval containing actual finite-temperature witnesses.

A tangent zero without opposite signs is insufficient. A zero exactly at β = 0 or infinity is a limiting statement, not a finite preparation. For a strong effect, additionally find zeros of b itself: split at the stationary points, check each strictly monotone interval for opposite endpoint signs, and count stationary zero points separately. General transcendental equalities require proof or rigorous enclosures; floating-point tolerances do not decide them.
