The classification working note is a historical working document; use the focused
paper and comprehensive report for the assembled presentation. Adjacent `.log`
files are historical build records.

The 25% result concerns an asymptotic slow-mode amplitude advantage. It is not a
measured refrigeration gain or a universal percentage reduction in cooling time.
The broader report also treats models with different hypotheses; read those
hypotheses before transferring a conclusion between examples.

Publication stripped identifying document metadata while preserving page content.

[Reproducing the research](../../REPRODUCING.md).
